# Java Employee Management System (EMS)

This is a simple desktop-based Employee Management System built using Java Swing. 
It allows users to add, view, and manage employee details with a user-friendly interface.

The main file to run the application is `Splash.java`.

## Features
- Splash screen
- Login system
- Add new employees
- View employee details
- Update and delete records
- Mark Attedance
- view attendace



  ## How to Run

1. Make sure you have Java (JDK 8 or higher) installed.
2. Compile and run the `Splash.java` file.

### Using Command Line:
```bash
java Splash.java
